# текущая архитектура

* ждёт ответы от ВСЕХ страховых
* блокируется сетевыми задержками
* падает при ошибке хотя бы одного партнёра

### Риски при росте:

* при добавлении ещё 5 страховых latency увеличится линейно
* возрастёт вероятность timeout
* cascade failures

## Pull-модель обновления данных

* данные устаревают
* нет гарантии доставки
* ошибки не ретраятся
* нагрузка пиковая


##Нет гарантированной доставки данных

* aggregator упал данные просто теряются.
