Для реализации онлайн ОСАГО мы используем Event-Driven архитектуру.

core-app синхронно создаёт заявку в osago-aggregator, после чего все предложения от страховых компаний передаются асинхронно через Kafka.

osago-aggregator выполняет оркестрацию, отправляет заявки во все страховые компании и опрашивает их API. Для отказоустойчивости применяются Timeout, Retry, Circuit Breaker и Rate Limiting.

Полученные предложения публикуются в Kafka с использованием Transactional Outbox, что гарантирует согласованность между БД и брокером сообщений.

core-app подписывается на события и транслирует предложения пользователю через Server-Sent Events, обеспечивая realtime UI.

Такое решение позволяет масштабироваться горизонтально, избегать блокирующих вызовов и отображать предложения по мере их поступления.


паттернов отказоустойчивости: 
Timeout - 60s max

Retry (with backoff) - на api errors

Circuit Breaker -если страховая умерла

Rate Limiting - чтобы не убить партнёров

Web → core-app Rate Limiting - 2500 пользователей — легко DDOS самим себя
